- Key cố định cho test (**không** dùng ngoài spike):
  - `K_gw` = `0x11` × 16, `key_id` = 1;
  - `K_gs` = `0x22` × 32;
  - key Retry của gateway = `0x33` × 32.
- `server_id` dạng 32 ký tự hex: `000000000000000000000000000000a1` (S2), `…a2` (S1), `…a3` (S4).
- **Routing ticket** (spec §3.2), tổng cộng 60 byte:

  | Byte | Trường |
  |---|---|
  | `[0]` | `ver` = 1 |
  | `[1]` | `key_id` |
  | `[2..14]` | nonce |
  | `[14..44]` | AES-128-GCM(body) |
  | `[44..60]` | tag |

  - AAD = `bytes[0..2]`.
  - body = `server_id(16) | session_id(8) | expiry(u32 BE) | transports(u8) | flags(u8)`.
  - Bitmask `transports`: native = 1, webrtc = 2, webtransport = 4.
  - **ufrag** = base64 chuẩn, không padding (80 ký tự).
  - **SNI** = base32 RFC 4648 chữ thường, không padding (96 ký tự), chia `48.48` rồi nối `.wt.test`.
- **ICE pwd**: `base64_std_nopad(HMAC-SHA256(HKDF-SHA256(ikm=K_gs, salt=rỗng, info="glassy-ice", L=32), ufrag))` → 43 ký tự.
- **Token Retry no-shared-state** (spec §3.6):
  - token = `byte0 | ODCID | expiry(u64 BE) | tag16`, với `byte0` = ODCIL (bit 7 = 0, ODCIL nằm trong 8..20).
  - `tag16` = `HMAC-SHA256(key, byte0 | ODCID | expiry | ip16 | port(u16 BE) | RSCIL(u8) | RSCID)[0..16]`.
  - `ip16` = 16 byte; với IPv4 là 4 byte địa chỉ + 12 byte 0.
- Findings ghi vào `docs/superpowers/spikes/2026-10-21-sp0-findings.md`. Mỗi mục theo khung: **Câu hỏi / Bằng chứng (lệnh + output) / Kết luận (đạt, hay kích hoạt fallback nào) / Việc cho sub-project sau**.

## Review Focus

1. **Browser gửi lại gói mở đầu** (STUN retransmit, Initial retransmit, hai lần cùng một 5-tuple) → relay chỉ tạo **một** flow và gói lặp vẫn đi đúng flow đó. Test: Task 3 `duplicate_stun_same_tuple_single_flow`, Task 9 `duplicate_initial_same_tuple_single_flow`.
2. **Ticket hết hạn hoặc sai key** → drop im lặng: không trả gì cho client, không gửi gì cho backend (không tạo ra khuếch đại). Test: Task 3 `expired_ticket_dropped_silently`.
3. **Datagram chứa nhiều gói QUIC ghép (coalesced)** → parser chỉ xử lý gói Initial đầu tiên và trả về đúng số byte đã đọc. Test: Task 6 `coalesced_datagram_consumed_len`.
4. **ClientHello trải 2 datagram nhưng một nửa không tới** → sau 100ms bỏ buffer, không tạo flow, không rò rỉ bộ nhớ. Test: Task 9 `incomplete_hello_times_out_and_clears`.
5. **Script AWS bị lỗi giữa chừng** → mọi resource đã tạo vẫn bị xoá, để tránh phát sinh chi phí. Test: Task 14 `test_teardown.sh` (kịch bản lỗi).

```rust
fn ring() -> KeyRing { KeyRing::new(1, [0x11; 16]) }
fn sample() -> RoutingTicket {
    RoutingTicket { server_id: [0xab; 16], session_id: [1,2,3,4,5,6,7,8], expiry: 2_000_000_000,
                    transports: transports::WEBRTC | transports::WEBTRANSPORT, flags: 0 }
}
#[test] fn seal_open_roundtrip() {
    let b = seal(&sample(), &ring(), [7; 12]);
    assert_eq!((b.len(), b[0], b[1]), (60, 1, 1));
    assert_eq!(open(&b, &ring(), 1_900_000_000).unwrap(), sample());
}
#[test] fn tamper_is_auth_error() { let mut b = seal(&sample(), &ring(), [7;12]); b[20] ^= 1;
    assert_eq!(open(&b, &ring(), 0), Err(TicketError::Auth)); }
#[test] fn unknown_key_id() { let mut b = seal(&sample(), &ring(), [7;12]); b[1] = 2;
    assert_eq!(open(&b, &ring(), 0), Err(TicketError::UnknownKey)); }
#[test] fn expired() { let b = seal(&sample(), &ring(), [7;12]);
    assert_eq!(open(&b, &ring(), 2_000_000_001), Err(TicketError::Expired)); }
#[test] fn bad_version_and_length() { let mut b = seal(&sample(), &ring(), [7;12]);
    assert_eq!(open(&b[..59], &ring(), 0), Err(TicketError::Length)); b[0] = 2;
    assert_eq!(open(&b, &ring(), 0), Err(TicketError::Version)); }
#[test] fn ufrag_roundtrip() { let b = seal(&sample(), &ring(), [7;12]); let s = to_ufrag(&b);
    assert_eq!(s.len(), 80);
    assert!(s.chars().all(|c| c.is_ascii_alphanumeric() || c == '+' || c == '/'));
    assert_eq!(from_ufrag(&s).unwrap(), b); assert_eq!(from_ufrag("ab"), Err(TicketError::Length)); }
#[test] fn sni_roundtrip_case_insensitive() {
    let b = seal(&sample(), &ring(), [7;12]); let l = to_sni_labels(&b);
    let parts: Vec<&str> = l.split('.').collect();
    assert_eq!((parts.len(), parts[0].len(), parts[1].len()), (2, 48, 48));
    assert!(l.chars().all(|c| c == '.' || c.is_ascii_lowercase() || ('2'..='7').contains(&c)));
    let host = format!("{l}.wt.test");
    assert_eq!(from_sni(&host, "wt.test").unwrap(), b);
    assert_eq!(from_sni(&host.to_uppercase(), "wt.test").unwrap(), b);
    assert_eq!(from_sni("abc.other.test", "wt.test"), Err(TicketError::Encoding));
}
```
